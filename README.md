A one-line office joke for make.fun's "One-Line Office Jokes" bounty ($2, five places paid). The program writes a single 92-character line about the office printer to `/output/entry.txt`. Pure Python standard library, no network, fully deterministic.

## Run it

```
python3 main.py
```

Writes `entry.txt` to `/output` (`MAKEFUN_OUTPUT_DIR` overrides).
